# Reverspin

Canvas 2D와 TypeScript로 구현한 방향 반전 회피 게임 프로토타입입니다.

## 실행

Node.js 24 이상과 pnpm이 필요합니다. Node.js 24의 TypeScript 실행 지원으로 테스트를 실행하며 별도 테스트 의존성은 없습니다.

```sh
pnpm install
pnpm dev
pnpm test
pnpm build
```

게임은 페이지를 열면 바로 시작합니다. **Space**를 누를 때마다 공전 방향이 반전됩니다. 조작 안내는 세션 시작 후 4초 또는 첫 방향 반전까지 작게 표시됩니다. 게임 오버 후 버튼 또는 Space로 다시 시작합니다. 탭이나 창이 비활성화되면 게임 시간이 멈추고 간단한 일시 정지 오버레이가 표시됩니다.

## 코드

- `src/game.ts`: DOM과 독립된 상태, 공전, 운석 생성/이동/제거, 충돌, 무적, 점수, 난이도
- `src/input.ts`: Space 입력과 키 반복/포커스 복구 처리
- `src/render.ts`: 논리 좌표를 Canvas에 매핑, 크기/DPR 대응, 도형 렌더링
- `src/main.ts`: DOM HUD, 재시작, 활성 상태, 하나의 requestAnimationFrame 루프
- `src/style.css`: 반응형 레이아웃과 오버레이
- `tests/game.test.mjs`: 시뮬레이션과 입력 회귀 테스트

## 2차 조정값

논리 영역은 800×800, 공전 반지름은 100, 플레이어 반지름은 12입니다. 공전 속도는 3.4 rad/s이며 한 바퀴는 약 1.85초입니다. 기존 반지름 220 / 1.8 rad/s / 약 3.49초보다 작은 궤도를 빠르게 돌아 방향 반전 타이밍에 집중하도록 조정했습니다. 체력은 3이며 충돌 후 0.5초 동안 무적입니다.

| 종류 | 반지름 (지름) | 속도 배율 | 기본 속도 범위 | 출현 확률 | 표현 |
| --- | --- | --- | --- | --- | --- |
| Normal | 17 (34) | 1.0 | 150→280 | 60% | 주황색 |
| Heavy | 30 (60) | 0.65 | 97.5→182 | 25% | 어두운 주황색 |
| Swift | 9 (18) | 1.65 | 247.5→462 | 15% | 밝은 노란색 |

속도는 논리 단위/초이며 각 운석에 ±10% 편차가 적용됩니다. Heavy는 넓은 구간을 느리게 막고, Swift는 작은 공간을 빠르게 통과합니다. Normal을 가장 흔하게 유지했습니다.

운석은 화면 밖 반지름 600에서 시작해 반지름 660을 벗어나면 제거됩니다. 중앙의 목표점은 생성 방향과 수직인 선 위에서 궤도 반지름의 ±1.4배(±140)로 분산됩니다. 운석 중심의 직선 경로 중 약 72%가 궤도를 교차하고 나머지는 빗나갑니다. 운석 크기를 포함하면 위협 범위는 더 넓어집니다. 플레이어 위치와 무관하게 생성되고 이후 유도 없이 직진합니다.

기본 속도는 150에서 280, 생성 간격은 1.1초에서 0.45초로 120초 동안 선형 변화한 뒤 유지됩니다. 속도 증가는 새로 생성되는 운석에 적용되어 비행 중 갑작스러운 가속을 피합니다.

플레이 화면에는 점수와 체력만 지속적으로 표시합니다. 제목·방향 HUD·프로토타입 배지·설명 문구를 제거하고 Canvas가 창의 가로/세로 공간에 맞는 최대 정사각형을 사용하도록 했습니다. 논리 좌표와 DPR 매핑은 유지합니다.

생존 1초마다 10점을 얻습니다. 프레임 간격은 최대 0.05초로 제한하고 충돌 처리는 최대 1/120초의 작은 단계로 나눕니다.

플레이 테스트에서는 공전 속도, 운석 생성 간격, 목표 편차, 운석 크기와 무적 시간을 우선 조정하면 됩니다.
